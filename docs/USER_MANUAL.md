## 1. 概要と主な機能

本ツールは、動画ファイル名に含まれる作品ID（品番）を自動識別し、WebスクレイピングおよびGemini AIを活用して以下の情報を一括取得・ファイル名の統一整形を行います。

- **メタデータ取得**: タイトル、出演者（女優名）、発売日、メーカー、シリーズ、ジャンル、カバー画像
- **自動ID抽出**: Standard (ABC-123)、FC2 (FC2-PPV-123456)、MGS (123ABC-456) 等の自動認識
- **Gemini AI フォールバック**: Webサイトのアクセス制限時（Cloudflare等）にGoogle Gemini APIが自動補完
- **ドライラン（シミュレーション）**: 物理リネームの前に、名前衝突や重複を検出・可視化
- **安全設計**: ログ表示、一括/個別リネーム切り替え、トラブルシューティングモーダル

## 2. 画面構成と基本操作

ヘッダーナビゲーションにより3つの表示モードを切り替えられます。

1. **WPF シミュレータ**: 動画ファイルのリネーム、メタデータ取得、プレビュー、各種設定を行うメイン操作画面です。
2. **C# 実装コード規約**: バックエンドC# / .NET 8.0 移植時のクラス・デザインパターン規約を確認できる仕様ドキュメント表示画面です。
3. **アーキテクチャ・設計図**: クラス図、シーケンス図、データフロー図をグラフィカルに表示するアーキテクチャ設計画面です。

## 3. ファイル追加と品番抽出

### 3.1 ファイルの追加方法
- **ドラッグ＆ドロップ**: メインテーブル領域に対象動画ファイル（.mp4, .mkv, .avi等）をドラッグ＆ドロップします。
- **「ファイル追加」ボタン**: テーブル上部の「ファイル追加」ボタンをクリックしてダミーファイルを追加・テストできます。

### 3.2 品番（作品ID）の自動抽出
ファイル追加時、設定されている正規表現ルールに基づいて作品IDが抽出されます。
例:
- `SSIS-123_sample.mp4` -> 品番: `SSIS-123`
- `[FC2-PPV-102934] sample.mkv` -> 品番: `FC2-PPV-102934`

独自の品番形式が存在する場合は、「設定パネル」の「カスタム品番ルール」より正規表現パターンを追加可能です。

## 4. メタデータ取得とAI補完

### 4.1 メタデータ一括取得
テーブル上のファイルを選択し、「全選択メタデータ一括取得」をクリックします。
バックエンドのオーケストレーターが起動し、各プロバイダーへ並列リクエストを送信します。

### 4.2 Gemini API 接続テストとAI補完
Webサイトがアクセス制限（Cloudflare 403 Forbidden等）を返した場合、自動的にGemini AIフォールバックが機能します。
Gemini APIキーは、「Gemini API 接続テスト」エリアよりテストおよび設定が可能です。

## 5. リネームルール設定とプレビュー

### 5.1 プレビュー表示
テーブルで選択されたファイルの変更前・変更後の比較（Diffハイライト）が「選択ファイル詳細プレビュー」領域にリアルタイム表示されます。

### 5.2 プリセット選択
- **標準形式**: `{id}_{title}` (例: `SSIS-123_サンプルタイトル.mp4`)
- **出演者別**: `{actress}/{id}_{title}` (例: `三上悠亜/SSIS-123_サンプルタイトル.mp4`)
- **メーカー・日付別**: `{maker}/{date}_{id}` (例: `S1/2026-08-01_SSIS-123.mp4`)

---

## 6. 一括リネームと安全処理（ドライラン）

1. **チェックボックス選択**: テーブル左端のチェックボックスで対象ファイルを選択します。
2. **「一括リネーム実行」クリック**: 選択中の全ファイルに対してファイル名変更処理を適用します。
3. **衝突・重複防止**: 同名ファイルが存在する場合、自動的にステータスが「衝突/エラー (error)」に指定され、上書きを防止します。

---

## 7. 設定画面とログ確認

### 7.1 WPF MVVM バインディング設定
- **並列処理数 (Max Concurrency)**: 同時リクエスト数 (1〜10)
- **アクセス間隔 (Delay ms)**: サーバー負荷軽減用のウェイト時間 (500ms〜5000ms)
- **重複スキップ / キャッシュ利用**: ON/OFF 切り替え

### 7.2 Console Log (Serilog / ILogger)
リアルタイムでアプリケーションログを出力します。
- **📋 ログをコピー**: 全ログをクリップボードへコピー
- **💾 ログ保存**: `.log` ファイルとしてローカル保存
- **🗑 ログクリア**: 画面上のログ消去

## 8. トラブルシューティングモーダル

エラー発生時、テーブルのステータスバッジ（例: `ERROR` / `NOT FOUND`）をクリックすると「トラブルシューティングモーダル」が起動します。
原因・具体的な解決手順・トラブルシューティングガイド (`docs/TROUBLESHOOTING.md`) への直接参照が表示されます。
