## 1. インストール・動作環境

### Q1.1 サポートされている動作環境を教えてください
- **OS**: Windows 10/11, macOS (12以上推奨), Linux (Ubuntu 20.04以上)
- **Node.js**: v18.17.0 以上（v20 LTS を推奨）
- **ブラウザ**: Google Chrome, Microsoft Edge, Safari, Firefox の最新版

### Q1.2 Docker環境やコンテナ環境でも動作しますか？
はい。Node.js v18以上が動作する環境およびPlaywrightに必要な依存ライブラリ（Chromium実行環境）がインストールされているコンテナであれば動作可能です。

## 2. 実行・起動

### Q2.1 `npm run dev` 実行時に `Port 3000 is already in use` と表示されます
ポート3000番が他のプロセスで使用されている場合に発生します。
- **対処法**: 他のプロセスを終了するか、環境変数 `PORT=3001` などを指定して起動してください。詳細は [TROUBLESHOOTING.md](./TROUBLESHOOTING.md#1-ポート3000番競合エラー) をご覧ください。

### Q2.2 ブラウザが自動起動しない・画面が開かない
ターミナルに表示される `http://localhost:3000` へブラウザから手動でアクセスしてください。

## 3. メタデータ取得・スクレイピング

### Q3.1 スクレイピング実行時に 403 Forbidden や Access Denied になります
一部のWebサイトではCloudflareなどのボット対策システムによりスクレイピングが制限される場合があります。
- **対処法**: 
  1. `.env` ファイルに `GEMINI_API_KEY` を設定してください。スクレイピング制限時もGemini AIフォールバックが自動起動し、メタデータ補完を継続します。
  2. 人間によるアクセスであることを確認するため、ブラウザモード（Playwright）の設定を調整してください。

### Q3.2 取得したメタデータのタイトルや出演者が空欄になります
動画ファイル名から品番（作品ID）が正しく抽出できていないか、対象サイト側に該当データが存在しない可能性があります。
- ドライラン（シミュレーション）画面で抽出された品番を確認してください。
- 独自の品番フォーマット（例: `CUSTOM-12345`）の場合は、設定画面でカスタム抽出正規表現ルールを追加できます。

## 4. Gemini AI フォールバック

### Q4.1 Gemini APIキーは必須ですか？
必須ではありませんが、**設定を強く推奨**します。
APIキー未設定の場合でもローカルルールおよび通常のWebスクレイピングは機能しますが、スクレイピング失敗時（ブロック時や非定型タイトル時）の高度なAIメタデータ推定機能が利用できません。

### Q4.2 Gemini APIキーの取得方法を教えてください
1. [Google AI Studio](https://aistudio.google.com/) にアクセスします。
2. Googleアカウントでログインし、「APIキーを作成 (Create API Key)」をクリックします。
3. 発行されたキーをプロジェクトルートの `.env` ファイル内の `GEMINI_API_KEY=YOUR_KEY` に記述してください。

## 5. リネーム・ルール

### Q5.1 リネーム実行前に結果を確認できますか？
はい。本ツールはデフォルトで安全な**ドライラン（シミュレーション）モード**で動作します。実際にファイル名が変更される前に、変更前後の比較と重複・衝突の有無をプレビュー画面で確認できます。

### Q5.2 リネーム後のファイル名フォーマットをカスタマイズできますか？
はい。設定画面から出力フォーマットテンプレート（例: `{maker}/{date}_{id}_{title}` や `{actress}/{id}` など）を自由に編集可能です。

## 6. 配布パッケージ・アップデート

### Q6.1 Windowsユーザー向けのZIP配布パッケージはどこから入手できますか？
GitHubの [Releases](../../releases) ページから最新の `video-renamer-tool-v1.3.0-windows.zip` をダウンロードしてください。詳細なセットアップ手順は [INSTALL.md](./INSTALL.md) を参照してください。

### Q6.2 バージョンアップ（v1.2.x から v1.3.0）時に設定やデータは引き継がれますか？
はい。ブラウザの `localStorage` および `AppData/` フォルダ内の設定・キャッシュは引き継がれます。新しいバージョンのフォルダへ `.env` ファイルおよび `AppData/` フォルダを移行してご利用ください。
