# 📖 動画ファイル一括リネームツール (Video Renamer Tool) ユーザーガイド

本ドキュメントは、動画ファイル一括リネームツールの操作方法、各種機能の使い方、およびトラブルシューティングガイドです。

---

## 🚀 1. 初回セットアップ (Initial Setup)

### 動作環境
- **ブラウザ環境**: Chrome, Edge, Firefox, Safari (最新版推奨)
- **Node.js**: v18.0.0 以上 (ローカル開発時)

### 起動方法
1. ブラウザでアプリケーションを開きます。
2. ヘッダーのステータスインジケーターが「接続完了」となっていることを確認します。

---

## 🎬 2. 基本操作 (Basic Usage)

### ステップ 1: 動画ファイルの読み込み
- 画面中央のファイル一覧エリアに動画ファイルをドラッグ＆ドロップするか、「+ 追加」ボタンから手動で追加します。

### ステップ 2: リネーム規則（テンプレート）の設定
- 右側の「WPF MVVM バインディング設定」パネルでリネームテンプレートを編集します。
- 使えるプレースホルダータグ:
  - `{id}`: 作品品番 (例: SSNI-001)
  - `{title}`: 作品タイトル
  - `{actress}`: 主演女優名
  - `{date}`: 発売日 (YYYY-MM-DD)
  - `{series}`: シリーズ名

### ステップ 3: メタデータ自動取得
- ツールバーの **「メタデータ取得」** ボタンをクリックします。
- 登録された作品IDをもとにDMM/FANZA Web API・スクレイピング・Gemini AIフォールバックが順次実行され、タイトル・女優名・発売日が自動補完されます。

### ステップ 4: プレビュー確認 & 実行
- テーブル内の「リネーム後ファイル名」を確認し、問題がなければ **「リネーム物理実行」** ボタンをクリックします。
- 誤って実行した場合は **「Undo」** ボタンで直前の状態にロールバックできます。

---

## 💾 3. 設定バックアップ & インポート (Settings Backup & Import)

### 設定のJSON出力・インポート
- 右側パネルの **「設定 JSON インポート / エクスポート」** セクションを使用します。
- **設定JSON出力**: 現在のリネームテンプレート・正規表現・Gemini設定を `.json` ファイルとして保存します。
- **設定JSON読み込み**: 保存した設定 `.json` ファイルを選択して一括復元します。

### 状態バックアップ & ポイント復元
- リネーム実行前に **「バックアップ作成」** を押すことで、現在のファイルリストと設定状態のスナップショットをLocal Storageに保存できます。
- リストから **「復元」** ボタンを押すことで、過去のバックアップ状態へ即座に戻せます。

---

## 📜 4. 履歴管理 (History Management)

- **アクティビティ履歴**:
  - 最近使用したリネームテンプレート
  - 最近実行されたリネーム処理（変更前→変更後）
- 履歴は自動的に保持され、**「全履歴消去」** ボタンで一括クリア可能です。

---

## 🔍 5. ログ確認方法 (Log Viewer & Search)

- 画面右下の **「Console Log (Serilog / ILogger)」** パネルでアプリケーションの動作ログを確認できます。
- **検索**: 検索窓にキーワードを入力してログメッセージをフィルタリングできます。
- **レベル別表示**: Debug, Info, Warning, Error で切り替え可能です。
- **日付フィルター**: 特定の日付範囲のログのみを表示できます。
- **ログの保存・コピー**: 「ログをコピー」または「ログ保存」ボタンでテキストデータとして取り出せます。

## ❓ 6. トラブル時の対処 (Troubleshooting)

| 現象 | 原因 | 対処方法 |
| :--- | :--- | :--- |
| **品番が抽出されない** | ファイル名の命名規則が特殊 | 正規表現パターンを「ハイフン無 (ABC123)」に変更するかカスタム表現を入力 |
| **メタデータ取得失敗** | ネットワーク遮断 / ブロック | Gemini API キーを設定してAIフォールバックを有効化するか、ログビューアのエラー詳細を確認 |
| **リネーム後ファイル重複** | 同一タイトルのファイルが存在 | 設定で「重複を連番回避」チェックボックスをONにする |
| **操作を戻したい** | リネーム実行の誤操作 | ツールバーの「Undo」ボタンを押すか、バックアップパネルから復元 |
